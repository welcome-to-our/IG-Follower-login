# IG-Followers Safe Login Demo

A visual login-page demo inspired by the supplied screenshot.

## Files

- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — local demo behavior

## Privacy

This demo intentionally does **not** send usernames or passwords anywhere.
There is no Discord webhook, backend, credential collection endpoint, or
third-party authentication.

## GitHub Pages

1. Create a GitHub repository.
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Select deployment from the `main` branch and `/ (root)`.
5. Save and open the generated Pages URL.
